1. So Sánh: Làm Đơ UI vs requestIdleCallback

requestIdleCallback

Quan sát quả cầu animation bên dưới. Chạy đồng bộ sẽ làm quả cầu đứng hình lập tức; chạy qua requestIdleCallback giữ vững 60fps.

Đã xử lý: 0 / 1000 timeRemaining(): -- ms
